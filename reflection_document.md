# Reflection

**1. Strengths and Weaknesses of AI-Assisted Documentation Workflows**
AI tools significantly sped up the drafting process by instantly generating standard Markdown templates, headers, and code blocks. However, a major weakness is that the AI does not understand the actual context of a project unless deeply prompted, meaning it can generate plausible but incorrect code dependencies or structural paths that must be manually fixed.

**2. Ethical Practices and Validation**
To ensure ethical use, I strictly used the AI as a design assistant rather than a code generator, avoiding feeding it any personal data. I maintained originality by manually validating every output using standard Markdown preview tools to ensure headers and code chunks rendered correctly before finalizing the files. 

**3. Iterative Prompting Process**
My process improved output quality by starting with a broad "Seed Prompt" for basic structure, following up with a "Refinement Prompt" to add specific sections like Installation and License, and finishing with a "Critique Prompt" to check for syntax errors. This iterative approach resulted in a much cleaner and more professional final draft.
