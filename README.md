# Synthetic Sales Data Analysis

## Overview
This R project analyzes a synthetic dataset of retail sales to identify seasonal trends and revenue distribution. It uses standard data manipulation and visualization libraries.

## Installation
To run this project locally, ensure you have R and RStudio installed. 
Install the required packages using the following command:

```R
install.packages(c("dplyr", "ggplot2", "readr"))
```

## Example Usage
Load the main script to generate the sales visualizations:

```R
source("scripts/sales_analysis.R")
generate_sales_report("data/synthetic_sales.csv")
```
